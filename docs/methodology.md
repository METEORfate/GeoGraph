# 加玛矿区观测数据三维表达方法

## 数据与几何

使用 `Jiama geochemistry data 2020.8.30-iogas.xlsx` 主表 `data` 的 9,021 个地表样本，以及 `数据库-川大 2025.4.29.xlsx` 的 477 个孔口和 114,082 条分析区间。每条记录通过文件名、工作表和 Excel 行号追溯。辅助表 `Sheet3` 的 1,963 个编号已存在于主表，作为核对数据，不重复建模。

地表点坐标为 `(East, North, H)`。辅助表核对采用 `(X − 16,000,000, Y, H)`；钻孔坐标采用 `(EAST − 31,000,000, NORTH, H海拔)`。辅助表样本 `2012606-1498` 的北坐标为 32852160，而主表为 3285216；保留冲突记录，空间表达采用主表值。

用户确认所有钻孔垂直。分析区间上下端点分别为 `(E, N, H − FROM)`、`(E, N, H − TO)`。未使用 INT 替代区间边界，未将分析间隙插值或连接成有含量的区间。保留 330 处间隙、14 条 INT 与 TO−FROM 差异大于 0.02 m 的记录。4 个无分析记录的孔仅保留孔口。空间尺度为 1:1:1，使用正交投影；渲染共同原点平移不改变存储坐标与相对几何。

## 坐标系辨识的证据与限制

6°第16带和3°第31带与中央经线93°E的解释相容。但带号、坐标数量级与DEM残差不足以唯一辨识大地基准。项目使用EPSG:4540作为暂定DEM配准解释，原始坐标系状态仍为“未确认”。

使用PROJ/pyproj对CGCS2000、西安1980、北京1954（均中央经线93°E的高斯投影）与WGS84/UTM46N进行首轮比较。中国基准到WGS84在此环境中报告为Ballpark geographic offset，精度未知，不能把投影反算当作经过控制点验证的基准转换。北京1954的结果也不能代表使用可靠地方转换参数后的结果。

## DEM、高程补值及像元定位

采用Copernicus GLO-30 Public COG瓦片 `Copernicus_DSM_COG_10_N29_00_E091_00_DEM`，1角秒采样间隔（约30m），高程采用EGM2008。该数据是DSM，会包含地表覆盖物，也可能与矿区采掘前后的地形不同。下载源、ETag、Last-Modified、实际文件SHA256与采集时间记录于manifest；镜像未提供明确发行版本，故不虚构版本号。

GeoTIFF标记为`AREA_OR_POINT=Point`。Rasterio/GDAL返回的仿射变换已将栅格原点转换为像元边界，必须通过该变换再减半个像元来求中心索引；首个像元中心为(91°E,30°N)。双线性插值要求四个邻居有效，不在覆盖外外推，不以0替代NoData。

**规划阶段数值修正：**此前直接读取TIFF的tiepoint并按像元边界解释，造成半像元位置偏差。当时地表MAE/RMSE为15.62/28.61m。正式流程使用Rasterio正确处理PixelIsPoint，以下结果取代规划阶段结果，自动化测试验证实际栅格像元中心与原值的一致性。

| 候选解释 | 地表 MAE / RMSE (m) | 孔口 MAE / RMSE (m) |
|---|---:|---:|
| CGCS2000 / 93°E | 14.40 / 28.03 | 58.78 / 96.63 |
| 西安1980 / 93°E | 14.52 / 28.09 | 58.92 / 96.76 |
| 北京1954 / 93°E，近似转换 | 32.43 / 42.37 | 65.53 / 102.14 |
| WGS84 / UTM46N | 242.95 / 304.65 | 112.87 / 159.39 |

地表n=1,963、孔口n=477；残差定义为原始高程减DEM插值高程。这里的MAE/RMSE是配准与高程综合残差，不是DEM独立精度验证。未进行拟合平移、残差最小化校准或删除大残差点。地表有效高程的空间分布仅覆盖部分采样范围，误差不能直接推广到全部补值点；两类原始高程的基准也尚未确定。

保留1,963个有效原始地表高程。其余7,048个空H和10个0.26–2.35的异常H由DEM补值，保留原H与missing_height/suspect_height标记。项目用3,500<H<6,500m筛查有效高程；这是针对现有数据的筛查范围，不是普遍规则。孔口从不被DEM覆盖，也不自动施加垂直偏移。三维图中的原始与估算高程属于暂定联合表达，应在正式论文中披露潜在垂直基准不一致。

用于显示的地形网格每60项目米采样，以控制浏览器负荷；点高程仍直接从原始DEM插值。显示网格不被描述为更高精度地形。DEM来源及处理说明随图导出。

## 元素、筛选和颜色

Cu、Mo、Pb、Zn等共有元素统一到ppm，质量百分含量乘10,000。氧化物名称保持独立，百分含量不与对应元素直接合并。颜色为连续顺序色带，支持线性或log10；零值与缺失值分开，对数映射不添加任意小常数。没有所选元素的对象显示缺失色。孔口不具有区间化验含量，始终保持类型色。

默认色域是全体来源中所选化学字段的有效数值范围，对数模式用正值范围。筛选不改变色域，手动色域外的对象使用端点色并计数。用户应在论文中记录筛选范围、色域、映射和视角，配套保存视图JSON。点大小、线宽仅用于可见性，不代表采样支撑体积或矿体厚度。

地表与钻孔具有不同采样介质、支撑尺度与可能不同分析方法；统一单位只是显示比较，不意味着数据可直接合并训练。深度学习前还需核实检测限、QA/QC、标签定义、空间采样偏倚和空间独立验证。

## 建议的论文方法表述

将地表地球化学样本表示为离散空间点，将经用户确认的垂直钻孔分析区间表示为由孔口高程与起止孔深计算的独立线段。原始平面坐标去除带号前缀后在局部米制坐标中联合展示。由于原始大地基准缺少测绘元数据，暂以CGCS2000、中央经线93°E的高斯–克吕格投影进行公开DEM配准，并保留该假设的不确定性。保留有效原始高程，对缺失与异常地表高程使用Copernicus GLO-30 DSM双线性插值估算，单独记录高程来源。元素颜色在统一质量浓度单位后按固定范围映射，且不填补分析区间间隙。本模型用于观测数据探索，不用于直接推断矿体边界或储量。
